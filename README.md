# ViPlayer

Минималистичный Android-плеер для длинных аудиолекций и подкастов (аудио и видео),
скачанных заранее и разложенных по папкам. Задача: включить и убрать телефон в карман,
дальше всё работает само. Управлять можно кнопкой гарнитуры.

## Установка

Скачайте свежую APK на телефон:
**https://github.com/sgvoxlink/ViPlayer/releases/latest/download/ViPlayer.apk**

Откройте файл и разрешите установку из этого источника. Новые версии ставятся поверх старых,
данные (отметки, плейлист, позиции) сохраняются.

## Возможности

- **Папки.** Выбираете одну или несколько папок, приложение сканирует их вместе с подпапками.
  Каждая подпапка становится разделом библиотеки («Космос», «Философия / Кант»…).
  Файлы сортируются по имени естественно: «Лекция 2» идёт раньше «Лекция 10».
- **Работа в фоне** с выключенным экраном, управление из уведомления и с экрана блокировки
  (там же кнопки −30 с / +30 с).
- **Кнопка гарнитуры:** 1 нажатие — пауза / продолжить, 2 — следующий файл, 3 — назад на 30 секунд.
  Если приложение выгружено, нажатие на гарнитуре продолжает последнее воспроизведение.
- **Автопауза**, когда отключаются наушники (провод или Bluetooth).
- **Прослушанное не повторяется.** Файл помечается прослушанным, когда дослушан на 95%.
  При запуске папки или плейлиста прослушанные файлы пропускаются. Отметки можно снять вручную.
- **Позиция запоминается** для каждого файла: лекция продолжается с того же места
  (на 3 секунды раньше, чтобы не потерять нить).
- **Плейлист.** Собирается из любых папок (кнопка «+» у файла, выделение долгим нажатием,
  «непрослушанные в плейлист» для целой папки). Порядок меняется перетаскиванием.
  Показывает, сколько осталось слушать с учётом скорости: «осталось 7 ч, при 1.5× — 4 ч 40 мин».
  Когда плейлист заканчивается, воспроизведение останавливается.
- **Скорость** от 0.75× до 3× без изменения тона. Есть опция «пропускать тишину».
- **Таймер сна:** через N минут, в конце текущего файла или в заданное время.
  Перед остановкой звук плавно затихает. Если включаете воспроизведение ночью
  (по умолчанию с 22:00 до 06:00), приложение само предложит таймер.
- **Видео:** по умолчанию играет только звук, что экономит батарею. На экране плеера
  можно переключиться в режим «Видео». С заблокированным экраном звук продолжается.

## Как пользоваться

1. Откройте **Библиотеку** и добавьте папку (значок папки с плюсом).
2. Нажмите на раздел, чтобы увидеть файлы. Нажатие на файл запускает его, а дальше
   играют следующие непрослушанные файлы этой папки. Кнопка ▶ в заголовке играет
   все непрослушанные файлы папки.
3. Соберите **плейлист**: «+» у файлов из разных папок, затем ▶ на вкладке «Плейлист».
4. Выберите скорость и, если нужно, таймер сна. Уберите телефон.

> Если воспроизведение обрывается в кармане (бывает на Xiaomi, Huawei, Samsung),
> в **Настройки → Работа в фоне** отключите для ViPlayer оптимизацию батареи.

## Технологии

| Задача | Библиотека |
|---|---|
| Воспроизведение, фоновый сервис, гарнитура, уведомление | [AndroidX Media3](https://developer.android.com/media/media3) (ExoPlayer + MediaSessionService) |
| Интерфейс | Jetpack Compose + Material 3 |
| База (файлы, позиции, отметки, плейлист) | Room |
| Доступ к папкам | Storage Access Framework, без широкого доступа к памяти |
| Перетаскивание в плейлисте | [Reorderable](https://github.com/Calvin-LL/Reorderable) |

Поддерживаемые форматы: mp3, m4a/m4b, aac, ogg/opus, flac, wav, amr, mka, mp4, mkv, webm, mov, 3gp, avi, ts, flv.

Минимальная версия: Android 8.0.

## Сборка

APK собирает GitHub Actions при каждом пуше в `main` (`.github/workflows/build.yml`)
и публикует её в Releases. Подпись берётся из секретов репозитория `KEYSTORE_BASE64`
и `KEYSTORE_PASSWORD` (PKCS#12).

Локальная сборка: откройте проект в Android Studio (JDK 17) или выполните
`gradle :app:assembleDebug`, если Gradle 8.11+ установлен.

## Структура

```
app/src/main/java/com/viplayer/
  ViPlayerApp.kt            контейнер зависимостей
  data/                     Room-сущности, DAO, сканер папок, репозиторий, настройки
  playback/                 PlaybackService (Media3), гарнитура, прогресс, таймер сна, связь с UI
  ui/                       экраны Compose: библиотека, папка, плейлист, плеер, настройки
```
